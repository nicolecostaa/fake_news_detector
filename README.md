# 📌 Sobre o Projeto

O **Fake News Detector AI** é um sistema web capaz de analisar notícias e identificar de serem falsas ou verdadeiras utilizando Inteligência Artificial Generativa.

Diferencie de modelos simples de Machine Learning tradicionais, este projeto utiliza:

✅IA contextual
✅Análise semânatica
✅Interpretação textual
✅Verificação de plausibilidade
✅Explicações automáticas



# 🎯 Objetivos

-Demosntrar uso de IA Generativa
-Aplicar APIs modernas de IA
-Trabalhar com análise textual
-Criar uma API REST como flask
-Desenvolver um sistema completo full stack
-Estudar detectação de Fake News
-Integrar Front-end + back-end + IA

# 🧠 Como Funciona
```text
Usuário digita uma notícia
↓
Front-end envia texto para Flask
↓
Flask envia prompt para OpenAI
↓
GPT-4o analisa contexto
↓
Sistema retorna:
- Probabilidade Fake
- Probabilidade Real
- Explicação
```
